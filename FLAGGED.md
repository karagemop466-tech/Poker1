# Flagged for Review

Published so you can review each item. Flags do not block the merge. Every flag keeps the text of the
official source it came from, and every flagged row carries the flag in `data/tournaments.json` so the
row itself says what is odd about it.

### Walking-time method, and why it is not an "official" figure

| # | Point | Detail |
|---|---|---|
| F49 | No hotel or poker room publishes a walking time. | The times on this site are **routed**, not published: they come from the OpenStreetMap foot network between geocoded coordinates, rounded up to the whole minute, and each row links both the geocoding lookup and the routing query so anyone can reproduce it. They are labelled `verified` against that routing source, never described as an official statement by the property. |
| F50 | The destination coordinate is the resort the poker room sits in, not the poker room door. | The Venetian poker room is inside The Palazzo and the Wynn poker room is inside Encore — both stated by the official sources quoted on the row — so the Palazzo and Encore coordinates are used as destinations, and the walk from inside the same building is marked `internal` rather than timed. An interior walk is therefore not included in any routed minute. |
| F51 | Four routed pairs fail the 30-minute rule. | ARIA → Venetian poker room 34 min, Bellagio → Wynn 31 min, Caesars Palace → Wynn 32 min, ARIA → Wynn 43 min. Every failing pair stays listed and flagged rather than dropped, so the rule is visible instead of silently applied. |
| F52 | A routing mistake was caught and corrected in this session. | The first router query used the Wynn **address** point as the destination for the Wynn poker room, but the official terms place that room in **Encore**. Re-running the query with the Palazzo and Encore coordinates as destinations changed several answers: Bellagio→Wynn went from 13 to 31 min and Caesars→Venetian from 33 to 23 min. The published values are the corrected ones, and the raw router output for both runs is in `research/verification-2026-11-17.md`. |
