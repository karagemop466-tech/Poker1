# Flagged for review

Everything on this page is published so you can review it yourself. Each item links to the official document it
comes from. **None of these blocks the site.**

Two kinds of item appear here:

* **F** — an irregularity in the official source itself, or a place where the official text is ambiguous.
* **U** — a value that could not be verified, so it is blank. A blank is deliberate.

## G. What the automated monitor records about these documents

Every official URL is re-fetched daily by a scheduled workflow. It stores a hash of each document's visible text
and records whether the content changed since the first check. The Source monitor page lists every document with
its result, its hash and the time of the check.

If a document cannot be fetched, the previous facts are kept and the run is logged as **unreachable**. A value is
never replaced with a guess, and a failed check never silently becomes a verified value.
