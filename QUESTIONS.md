# Questions and information gaps

Every question that has to be answered before a booking decision. Each row states what is **known**, what is
**missing**, and the **specific action** that would close it. Nothing in the "known" column is an inference: each
value is taken from the official document linked in the repository's source log.

Answer status: **closed** (an official document states it), **partly closed** (an official document states part of
it), **open** (no official document located).

## F. What has to be answered before paying anything non-refundable

1. **A1 and A2** — the dates and the nightly budget, because every other number depends on them.
2. **A3** — a dated official room quote, because the trip cost is otherwise incomplete.
3. **B2** — whether a busted flight can be re-entered, because it decides whether the big multi-flight events
   belong in the single-entry plan.
4. **C4** — whether multi-flight events are allowed, because a multi-flight event blocks later days.
5. **D1** — the walking plan, because it decides whether a non-host hotel is even in scope.
6. **A5 and D4** — the cancellation terms, because they decide how much risk the booking carries.
