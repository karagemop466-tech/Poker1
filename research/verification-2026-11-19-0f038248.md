## 3. What was deliberately NOT changed

- **No "unverified" label was removed.** The only rows whose entry rule is unknown are the
  34 Wynn Signature Series rows, and the single official document that could confirm them
  is the structures PDF, which still prints "COMING SOON". Re-reading the *schedule*
  cannot settle an entry rule, so the rows stay `UNV` and stay out of every ranking.
- **No candidate was promoted to single entry.** Sheets #5, #8 and #10 were read again and
  none of them prints a maximum-entry, rebuy or add-on rule; the Venetian poker page prints
  none either. Under this project's rule, that is silence, so `CAND` stays `CAND`.
- **No number moved.** Every compared field matched, so `buy_in_usd`, `guarantee_usd`,
  `house_fee_usd`, `prize_pool_usd`, `starting_chips`, `levels`, `level_minutes`,
  `late_reg_close` and `payout_excerpt` are untouched on all seven rows.
- What these seven rows did gain is the dated `last_checked: 2026-11-19`, a
  `retrieved_on: 2026-11-19` on each of their rule fields, and a note naming what the
  re-read found - so a reader can tell a document re-opened today from one carried over.
  No other row's date was advanced.

## 4. The derived spend-advantage column this session added

`data/tournaments.json` now carries one more descriptive field per row,
`spend_advantage`, produced by `scripts/spend_advantage.py` from the excerpt already stored
on that row. It answers the trip rule "can a player gain an advantage by spending more
here?" in the document's own terms:

| Derived value | Rows | What it means |
|---|---|---|
| `further-entry-priced` | 3 | The sheet puts a price on a buy-in after the first one (sheet #8 clause 07 pattern). |
| `rebuy-or-reentry-printed` | 114 | The sheet sells further entries while the event runs ("Unlimited re-entry … until the start of level 9/10"). |
| `later-flight-printed` | 43 | The sheet addresses a further starting flight and bars only a player who bagged chips (clause 08 pattern). |
| `no-further-entry-clause` | 80 | Every numbered clause was read and none prices a later entry, a rebuy or an add-on - silence, not permission. |
| `no-structure-sheet` | 34 | No structure document exists for the event yet (the Signature Series placeholder). |
| `continuation` | 43 | A Day 2 / final-table row: the document sells no entry, so the question does not apply. |

Guarantees: the column never changes an `entry_status`; `scripts/check_links.py`
re-derives all 317 records from the stored excerpts on every build and fails if a value,
its quote, its source or its retrieval date disagrees with the row; a row whose reading is
`yes` can never carry the verified single-entry status; and
`scripts/test_spend_advantage.py` + `scripts/check_spend_filter.js` (headless) pin the
behaviour of the value, the table column and the new filter.
